# 中央の共有モニター

GameRoom.prefabのCenterStatusMonitorは、テーブル中央で各プレイヤーの頭の位置に向きます。回転はローカルで行い、他のプレイヤーの向きに干渉しません。操作用の4枚とは別の、表示専用モニターです。

- 大富豪：場のカード、縛りのスート、Jバック、革命、現在の強さの順序、手番・カード交換・終了状態。
- おやつ工房：累計の焼き上がり数による順位。約3秒ごとに同期し、6人ずつ約8秒でページを切り替えます。最大80人の現在の参加者を表示します。
- 対応データのないゲームやゲーム選択中：案内画面。

おやつ工房の生産・所持数・購入は本人のローカル状態です。4枚のどの操作モニターを使っても、同じ本人の進行を表示します。ランキングだけを共有し、購入によって累計スコアは減りません。退出した人はランキングから除外します。進行とランキングはインスタンス内のもので、永続保存ではありません。

## ゲームパッケージから表示する

ゲーム本体のMenSharpBehaviourに次のpublicフィールドを追加し、パッケージのEditorビルダーでTextを割り当てます。TextのGameObjectは非表示で構いません。

```csharp
public Text sharedPileLabel;  // 見出し・場のカード（短い1～2行）
public Text sharedStateLabel; // 状態やスコア一覧（最大6行）
public Text sharedTurnLabel;  // 手番・ページ番号など（短い1行）
```

ゲームの表示更新時に、この3つのTextのtextを更新してください。中央モニターは先頭の操作モニターにある、現在アクティブなゲームのデータを読みます。共有すべき値はゲーム本体側でネットワーク同期してください。本人だけの情報を渡した場合は中央モニターも本人だけの表示になります。

`Game Select > Refresh JSON Catalog`で自動接続されます。特定ゲームのクラスを中央モニターから参照しないため、パッケージをフォルダー単位で取り除けます。中央モニターの場所や大きさはPrefabで調整できます。
