# おみくじ

画面は通常のおみくじです。内部の抽選結果は中吉・大吉の2種類だけ（各50%）に固定しています。抽選中は連打を受け付けず、約0.85秒の演出後に結果と音を出します。

文章とラッキーアイテムはgame.jsonのsettings.messages / settings.luckyItemsで編集できます。画像・音声・プログラムはこのフォルダー内にまとまっています。.metaも含めて追加・削除してください。共通フォントはホスト側のNoto Sans JP（OFL）を使用します。画像はプロジェクト作成の図形、効果音は独自に合成した音です。

4モニターの起動・終了は共有、抽選結果と回数は各モニター／各プレイヤーのローカル状態です。回数はプレイセッション内で保持し、永続保存しません。
