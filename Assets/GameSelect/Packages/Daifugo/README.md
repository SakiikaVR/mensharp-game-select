# 大富豪

MenSharp製の最大4席の対戦ゲーム。人間1〜4人で参加し、CPU補充ONなら空席をすべてCPUで埋めて4席にします。CPU補充OFFなら人間2〜4人で遊びます。画像、解説音声、効果音、プログラム、game.jsonをこのフォルダーにまとめています。追加・削除は.metaを含めてフォルダー全体で行います。

## 操作

参加 → 配札 / 次の対戦。手札をクリックして選択し「出す / 効果を確定」、またはパス。自分の手札は各プレイヤーのローカル表示です。どのモニターから操作しても同じ対戦に参加します。観戦者には手札を表示しません。

歯車からルールを変更できます。ルール変更は待機中・最初の人間の参加者のみで、全員に同期します。結果画面から待機室へ戻ると参加受付と設定変更ができます。解説は初期OFF、効果音は初期ON。これらの音声設定は各プレイヤーだけに反映します。

## 標準ルール

53枚（ジョーカー1枚）。通常は3から2へ強くなります。単体ジョーカーは最強。同じ枚数と形でより強いカードを出します。パスした人は場が流れるまで復帰できません。初回はダイヤ3の所持者から、次の対戦は前回最下位から開始します。禁止上がりは初期ON。通常の2、革命中の3、8、ジョーカーを含む札で最後の手札を出すと反則負けで下位順位を確定します。Jバックだけでは禁止対象を入れ替えません。10捨てなど、効果で手札がなくなる場合はこの判定の対象外です。都落ち・数字縛りはありません。

1位と最下位は2枚、4人以上では2位と下から2位は1枚を交換。下位は強いカードを自動で渡し、上位は返すカードを選びます。CPUも交換します。

## 初期ONの12ルール

| ルール | この実装の処理 |
|---|---|
| 10捨て | 出した10の枚数だけ、手札から選んで捨てる |
| 12ボンバー | Qの枚数だけ数字を指定し、全員からその数字を除去。ジョーカーは対象外 |
| Jバック | 場が流れるまで強さを反転。再発動で再反転 |
| 8切り | 効果選択後に場を流す。上がっていなければ同じ人から |
| 縛り | 同じスート構成が続くと、その構成だけ許可。流れると解除 |
| 革命 | 同じ数字4枚以上で強さを反転 |
| 階段 | 同一スートの連番3枚以上。2と3の循環なし |
| 階段革命 | 階段4枚以上で革命。階段OFFなら発動しない |
| スペ3返し | 単体ジョーカーにスペード3を出し、縛りを無視して流す |
| 7渡し | 出した7の枚数だけ、次の未上がりの相手に手札を渡す |
| 5スキップ | 5の枚数だけ未上がり・未パスの席を飛ばす。一周で自分になる場合もある |
| 禁止上がり | 通常2・革命中3・8・ジョーカーでの最終手は反則負け（初期ON） |

複合効果は7渡し → 10捨て → 12ボンバー → 上がり判定 → 場を流す／次の手番。場を流す場合は5スキップより優先します。ジョーカーは不足1枚を補いますが、代用した数字の特殊効果は発動しません。同時に手札がなくなったら、出した人から席順に順位を決めます。ゲーム内の12ページのルールブックでも説明しています。

## CPU・同期

CPUは自分の手札と場から合法な組・階段を探索し、効果の選択と交換にも対応します。相手の手札は判断に使いません。約1.2秒間隔で操作します。

ルーム内の先頭モニターのUdonBehaviour所有者が対戦状態の唯一の更新者です。操作要求の送信者、席、手番、状態リビジョン、所有カードと合法性を検証します。同期変数から途中参加・所有者交代時の表示を再構成します。参加者の退出は手札除去と進行復旧を行い、交換中の退出は待機室へ戻します。全人間が退出すると部屋を空にします。

手札は通常UIでは本人だけに表示しますが、カード所有配列自体はVRChatの同期変数であり、暗号化された秘密情報ではありません。

## 検証

Editor/DaifugoRulesTests.Run()でルール境界、20回の基本対戦、30回のCPU対戦（最大4席）、カード交換を検証できます。ClientSimでは実際のUdon実行・CPU補充・配札・手札表示・操作要求・設定・音声を確認します。異なるPCのVRChat実クライアント間での対戦検証は未実施です。

相手の残り枚数は裏向きカード付きの大きな枠に表示し、手番の枠を緑色にします。上がった相手は順位に切り替わります。手札は独自のカード表面テクスチャを使った扇状配置で、選択時に持ち上がります。
